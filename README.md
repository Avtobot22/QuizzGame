# QuizzGame

TV-first приложение для квизов с друзьями. TV — основное устройство ведущего; телефоны присоединяются как устройства участников.

TV открывается гостем. При запуске игры, требующей аккаунт, нужен вход на самом TV. Телефон того же хозяина может оставаться гостевым: сессии устройств независимы. Игроки присоединяются по QR комнаты без обязательной регистрации. Эти сценарии пока описаны требованиями; сейчас доступны только стартовые демонстрационные экраны.

## Начало работы

Установить JDK 21, Android SDK Platform 37.0 и Build Tools 36.0.0. Открыть проект в совместимой Android Studio, указать SDK через `local.properties` или `ANDROID_HOME`.

```sh
./gradlew :app:mobile:assembleDebug :app:tv:assembleDebug
```

Запустить `:app:tv` на Android TV или `:app:mobile` на телефоне. Минимальная версия Android — API 26. Версии закреплены в `gradle/libs.versions.toml` и Gradle wrapper; daemon использует JDK 21. В Windows используется `gradlew.bat`.

## Структура

- `app/tv` — TV-приложение с TV Material и управлением D-pad.
- `app/mobile` — приложение участника с Material 3.
- `core/ui` — общий стартовый Compose-контент и ресурсы.

Будущие feature владеют собственными UI/presentation, domain и data. Общие предметные возможности выделяются в shared при появлении реальных feature-потребителей. Пустые модули не создаются.

## Проверка поведения

```sh
./gradlew :app:mobile:connectedDebugAndroidTest
./gradlew :app:tv:connectedDebugAndroidTest
```

Тесты запускать на устройстве соответствующей платформы. Проверять восстановление состояния, видимый TV-фокус, D-pad и Back. Release signing и публикация не настроены.

## Материалы и работа с Git

`docs/` содержит локальные документы и исключён через `.git/info/exclude`; при клонировании эти материалы не появятся. Локальные настройки, кэши, ключи и APK в Git не добавляются.

Первоначальная основа создаётся на `chore/bootstrap`. Из её initial commit формируется первая ссылка `main` пустого репозитория; последующие изменения идут только отдельными ветками и PR. Проверки качества и CI добавляются следующим этапом.
